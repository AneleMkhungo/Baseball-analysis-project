# Baseball-analysis-project
Project Overview

An Exploratory Data Analysis (EDA) project using the Lahman Baseball Database to analyze historical baseball statistics, identify player performance patterns and explore relationships between batting statistics.

Research Questions

1. Who are the best-performing batters based on home runs, batting average, RBI and OPS?
2. Does hitting more home runs relate to higher RBIs?
3. How has batting performance changed over time?
4. Which teams have the strongest offensive performance?
5. Are batting averages normally distributed?

Tools & Technologies

* Python
* Anaconda
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* SciPy

Dataset

Source: Lahman Baseball Database

Datasets used:

* Batting.csv
* People.csv
* Teams.csv

Analysis Techniques

* Data cleaning and preprocessing
* Handling missing values and duplicates
* Data aggregation using groupby()
* Feature engineering (AVG, OBP, SLG and OPS)
* Correlation analysis
* Descriptive statistics
* Normality testing
* Data visualization

Visualizations

* Bar charts
* Scatter plots
* Line charts
* Histograms
* Q-Q plots

Project Goals

The goal of this project is to strengthen my Python, Pandas and statistical analysis skills by applying data science techniques to real-world baseball data.
